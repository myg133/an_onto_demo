## 四 · 两个真发现（别当噪声）

### F-1 · 老项目名打不了包（更严重）

`bundle pack --project anspire_real`（下划线）**直接失败**：

```
项目名 `anspire_real` 不符合 schema 的 pattern ^[a-z0-9][a-z0-9-]{1,62}$
```

但 `anspire_real` 是**既有项目**（历史库里的真名）。⇒ **升级到 REQ-159 之后，凡项目名带下划线的历史项目都打不了包**。
需要拍板：放宽 schema 允许 `_`，还是给「项目改名」一条路。

### F-2 · `credential.suspect` 会误报列名

包内快照里有一列叫 `password`（业务列名）⇒ 触发「扫到可疑片段」。v1 只告警不拒（契约如此），
但**每个有 password 列的库都会稳定告警** ⇒ 警报疲劳。建议判据收紧成「`"password"\s*:\s*"…"`（带值）」或排除列名字段。
