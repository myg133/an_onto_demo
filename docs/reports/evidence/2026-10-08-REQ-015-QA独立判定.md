## B · 「0 违规」是不是判据空转？——**我的独立判断**
- 实测：规则 agent = 0 条违规；VendorModelAgent = 8 条。
  ⇒ **判据本身不是空转，它能查出真违规**，接线是真的。
- 但 Dev 那句「声明逐列取自同一份 schema，必然一致」**成立且就是 0 的原因**：
  `RuleBasedAgent` 的 ColumnRef 是从 `table.columns` 现取的，不是独立声明，
  所以 UnknownTable/UnknownColumn 在结构上不可能发生 —— 这是**同义反复**。
- 关键判断：**换成真 agent（RN-2）这条推理立刻失效。** 模型输出与 schema 无
  任何构造性关联，同一份代码就会产出非 0。所以 0 违规不能当「阶段 2 已验证有效」
  的证据，只能当「规则实现下无矛盾」。Dev 的措辞没有夸大，但**容易被读成前者**。
