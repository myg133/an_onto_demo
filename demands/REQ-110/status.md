## 两个障碍（本需求的存在理由）

| # | 障碍 | 证据 |
| --- | --- | --- |
| 1 | 产品没有 TTL 导出 | `ontok --help` 里无 `export` / `ttl` / `rdf` 子命令；这次是外部 Python 脚本转的 |
| 2 | 页面在浏览器里打不开 | `require_token` 是**全局 layer**（`http.rs:449-458`），`/` 也被拦 ⇒ 口令框永远等不到人 |

## 关键裁定

| # | 裁定 |
| --- | --- |
| R1 | 默认导出**客户视图**；`--model-view` 显式选建模视图 |
| R2 | 客户视图 TTL **必须过守门器**（TTL 是新出口，不过闸就是泄漏通道） |
| R3 | 有损项（`ActionType` / `semantic` / `cardinality`）头部**显式声明** |
| R4 | `/` 免 token，但**壳内零数据**；`/api/*` 全部仍 gated |
| R5 | `Content-Disposition: attachment; filename="<project>-v<n>.ttl"` |
| R6 | 同版本两次导出**逐字节相同** |
