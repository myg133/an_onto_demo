# 需求：REQ-111 · 本地审核界面（HTML 里做双轨审核）

## 基本信息

| 项 | 优先级 | 状态 | 前置 |
| --- | --- | --- | --- |
| REQ-111 | **P1** | 进行中 | **REQ-110 合并后开工**（两者都改 `page.rs` / `http.rs`） |

## 需求描述

### 现在审核长这样

```powershell
ontok review show --proposal p1 --project X
ontok review decide --item 3 --track biz --accept
ontok review decide --item 3 --track model --accept
ontok review decide --proposal p1 --accept-all     # 全接受
```

142 个条目 × 2 轨 = **284 次进程启动**（这个数字在 REQ-003 的验收里被记为「E2E 根本跑不完，15 分钟才走一半」）。

### 目标：在页面上逐条看、逐条签

```
ontok review serve --project X --proposal p1 --bind 127.0.0.1:8788
   ├─ 列表：每条的 业务轨/建模轨 状态、置信度、AI 理由、证据
   ├─ 逐条：接受 / 拒绝（两条轨各一次点击）
   ├─ 批量：接受全部 / 按档位批量（只接受 ≥0.90）
   └─ 实时进度：已签 / 待签 / 阻断
```

## 为什么必须是一个**独立命令**，而不是给 `serve` 加开关

| `serve` | `review serve` |
| --- | --- |
| **只读**：任何非 GET ⇒ 405 | **可写**：只有 `POST /api/decide` 一个写点 |
| 面向客户/业务看结果 | 面向 FDE 做审核 |
| 已冻结版本 | **只服务未冻结的提案** |
| REQ-093 的硬判据「没有可写的地方」 | 推翻那条承诺，所以**必须是另一个进程/命令** |

⇒ 加开关会让「serve 是只读的」这条从**结构保证**退化成**配置保证**。这正是这个仓库反复栽的坑。

## 范围

### 做

1. **`ontok review serve --project --proposal --bind --token`**：仅回环、仅本地
2. **`GET /api/review`**：返回提案条目 + 双轨决策状态 + 置信度 + AI 理由 + 证据
3. **`POST /api/decide`**：`{item, track, decision}` → 走**同一个** `review decide` 领域路径
4. **页面**：条目列表（可按档位/未签过滤）、逐条签、批量签、进度条
5. **只允许未冻结提案**：已冻结 ⇒ 启动即拒绝（fail-closed）
6. **写审计**：每次决策记 `decided_at` / `via: "review-ui"`（与 CLI 可区分）

### 不做

- ⛔ 不改 `serve`（保持只读，一行不动）
- ⛔ 不许远程访问（只绑回环）
- ⛔ 不做 `proposal apply`（应用仍走 CLI，避免「点了就生效」）
- ⛔ 不做多用户/权限体系（单机单人）

## 关键裁定

| # | 问题 | 裁定 |
| --- | --- | --- |
| R1 | 写接口的鉴权 | 必须 Bearer token（同 `serve`），且**只绑 `127.0.0.1`/`::1`** |
| R2 | 写接口的并发 | 单条决策是幂等覆盖（同 item+track 再签 = 改判），不需要乐观锁 |
| R3 | 决策落库路径 | **复用 `review decide` 的领域函数**，⛔ 不许在 HTTP 层直写 SQL（纪律 H） |
| R4 | 页面是否复用 `serve` 的页面 | 复用组件（图/表格样式），但**独立 HTML**，避免两套语义混在一个文件里 |
| R5 | 失败语义 | 决策失败必须让页面看到具体原因（例如「已冻结」），不许静默 |

## 风险

| # | 风险 | 缓解 |
| --- | --- | --- |
| 1 | 写接口被误暴露 | 只回环 + token + 启动时打印绑定地址；⛔ 非回环直接拒启动 |
| 2 | 与 CLI 决策不一致 | 同一个领域函数；AC 要求「CLI 签 A、页面签 B，结果一致」 |
| 3 | 批量签误操作 | 批量只接受「指定档位以上」，且必须先预览条数 |
| 4 | 已冻结仍能签 | 启动拒绝 + 每次写前再校验 |

## 交付物

5. 已知限制
