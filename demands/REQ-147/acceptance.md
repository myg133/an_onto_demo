# 验收标准：REQ-147

## 一 · AC

### AC-001 · 默认路径零变化（R1）

- 不给 `--agent` ⇒ `assertions.jsonl` / `stats.json` 与基线 `6f4987d` **逐字节相同**
- 判据：3 篇文档对拍 sha

### AC-002 · ACP 通路可用（输出 schema 一致）

- `--agent acp` ⇒ 产出合法的 `assertions.jsonl`（**与内置同 schema**）
- 同一份 JSONL 能被 `doc merge` 吃下（端到端跑通一次 merge）
- 判据：schema 对比 + merge 退出码

### AC-003 · 确定性（R2，**最容易漏**）

- 同一份输入跑**两次** ACP ⇒ `assertions.jsonl` **逐字节相同**
- 第二次 **0 次 agent 调用**（缓存命中）
- **变异**：去掉缓存 ⇒ 两次 sha 不同（必须有测试红）
- 判据：两次 sha + 调用计数

### AC-004 · 失败要响（R3）

| 构造 | 期望 |
| --- | --- |
| `--agent-acp-command` 指向不存在的程序 | 退出码非 0 + 点名 |
| agent 返回空/超时 | 退出码非 0，**不产出 assertions 文件** |
| 预算超限 | 停止 + 报"已用/上限"，**不产出半份** |

- ⛔ **不许静默回退到内置 LLM**（这条要有测试）
- 判据：三种构造各一次

### AC-005 · quote 机器校验（**本需求的核心价值**）

- 每条输出的 `quote` 必须能在原文里**逐字定位**
- 定位不到 ⇒ **该条丢弃**并计入 `discarded_no_quote`
- **变异**：故意输出一条编造的 quote ⇒ 必须被丢 + 计数 +1
- 判据：正常一次 + 变异一次

### AC-006 · 质量对照实验（**决定这个需求值不值得做**）

同一批文档（`.local/ops360-docs` 16 篇）跑两遍：

| 指标 | 内置 LLM | ACP + skill |
| --- | --- | --- |
| 概念数 | 301 | ? |
| 关系数 | 239 | ? |
| **`belongs_to` 命中率** | **0.0%** | **必须 > 0**（这是它存在的理由） |
| quote 校验通过率 | ? | **≥ 95%** |
| 谓词里"泛动词"占比 | 高 | 必须**显著更低** |

- **判据：如果 ACP 的 `belongs_to` 还是 0，本需求就失败**（不是"完成了"）
- 判据：贴两边的四组数字

### AC-007 · skill 通用性（R4）

- `grep` 项目/行业专有名词（腾讯 / 云服务器 / 巡检 / 订单 / CVM / CDB …）⇒ **0 命中**
- skill 里**不含**任何具体产品的类名或字段名
- 判据：grep 清单

### AC-008 · 不退化 / 零依赖

| 项 | 约束 |
| --- | --- |
| ⛔ 禁改 | 四红线 + `tools.rs` + `guard()` + `property_filter.rs` + `doc_merge.rs` |
| ⛔ 禁 | 新依赖；删测试；放宽断言 |
| 出口 | 新增写点登记 `OUTLETS` |
