## 基本信息

| 项 | 值 |
| --- | --- |
| 需求编号 | REQ-147 |
| 优先级 | **P1**（决定本体质量的上限） |
| 状态 | 进行中 |
| 基线 | `develop` `6f4987d` |
| 触发 | 用户：**ingest 现在用内置 LLM；建议用 ACP，并在 ACP 里加我们做的抽取 skill**（skill 要**通用**） |

## 问题（有实测数据）

`doc ingest` 现在**只有内置 LLM 一条路**（⛔ 无 `--agent` 参数），而 `ontok-propose` 早就有 `--agent` + `AcpAgent` 通路。

内置 LLM 在 Ops360 真实语料上的表现：

| 指标 | 实测 | 说明 |
| --- | --- | --- |
| 概念（去重） | 301 | 数量够 |
| 谓词 | 239 | **一堆动词**：「读取」「写入」「使用」「融合」… |
| **`belongs_to` 命中率** | **0 / 241 = 0.0%** | **一条真正的归属关系都没抽到** |
| 与真实表对齐 | **3 / 755** | 基本用不上 |

**原因**：内置 LLM 是**一次性问答**——没有工具、看不到全局、不能自我核对 quote。

## 要做两件

### 1 · `ontok doc ingest --agent acp`

```bash
ontok doc ingest --input docs/ --out a.jsonl --stats s.json \
                 --agent acp --agent-command "pi-acp" --agent-skill skills/ontok-extract
```

| 约束 | 说明 |
| --- | --- |
| **默认仍是内置 LLM** | ⛔ 不给 `--agent` 时**行为逐字节不变** |
| 输出 | **同一份 `assertions.jsonl` schema**（下游 merge / sign / 合并全不改） |
| **确定性** | 指纹缓存 ACP 回答；重跑**逐字节相同**（这是 TTL 可重放的前提） |
| 失败 | **大声报**（退出码非 0，⛔ 不许静默降级到内置 LLM） |
| skill 路径 | 由参数传入，⛔ 不写死在代码里 |

### 2 · 通用抽取 skill `ontok-extract`

**必须是通用的**：不含任何行业/项目专有名词， qualquer 文档都用它。

内容要点（我写，不由 Dev 编）：

| 节 | 内容 |
| --- | --- |
| 你要产出什么 | 概念 / 关系 / 属性，每条**必须带逐字引用** |
| 什么算概念 | 会被反复指代的名词性实体（⛔ 不是动词、不是一句话） |
| 什么算关系 | 两个概念之间的**稳定**关系；谓词必须是**名词化或明确的动词短语**，⛔ 不许「使用/读取」这类泛动词 |
| 证据 | `quote` 必须是原文**逐字**子串；`span` 必须对得上；找不到引用 ⇒ **不许输出该条** |
| 关系必须有方向与依据 | `from` / `to` / `predicate` / `evidence`，⛔ 不许凭常识补关系 |
| 禁则 | ⛔ 扩写原文、⛔ 合并别名（留到对齐轮）、⛔ 把「示例」当「定义」、⛔ 输出没有引用的条目 |

## 不做

- ⛔ 不改内置 LLM 通路
- ⛔ 不改 `assertions.jsonl` 的 schema
- ⛔ 不改 `doc merge` / `doc sign`
- ⛔ 不引依赖（ACP 传输已有）

## 关键裁定

| # | 裁定 |
| --- | --- |
| R1 | **默认关闭**；不给 `--agent` 时零字节变化 |
| R2 | **缓存必须是确定性的**：同 chunk 同回答，重跑逐字节相同 |
| R3 | **失败要响**：ACP 连不上 / 超预算 / 全部失败 ⇒ 退出码非 0 且**不产出半份文件**（沿用 REQ-116 的 N-1 纪律） |
| R4 | skill **通用**：判据是"`grep` 项目/行业专有名词 = 0" |
| R5 | 输出 schema 与内置路径**完全一致**（同一份 JSONL 能被 merge 吃） |

## 风险

| # | 风险 | 缓解 |
| --- | --- | --- |
| 1 | ACP 慢一个量级（95 块 × 起 agent） | 只对**质量关键**的轮次用；内置保持默认 |
| 2 | agent 不守契约（quote 编造） | **机器校验**：quote 必须能在原文定位；不过 ⇒ 该条丢弃并计数 |
| 3 | 成本不可控 | 沿用 `--budget-tokens` 闸 |
| 4 | skill 写得太"聪明"，塞了行业判断 | R4 的 grep 判据 |
