# 验收标准：REQ-131

## 一 · AC

### AC-001 · 缺夹具 ⇒ 响亮跳过、不失败

- 在**缺夹具**的环境跑受影响的用例 ⇒ **退出码 0**（测试成功）
- 输出里有可 grep 的固定标记，含：用例名 + 缺什么 + 「这条判据没有执行，不是通过」
- 判据：贴真实输出；`Select-String 'SKIP'` 能数出条数

### AC-002 · 可强制：`ONTOK_REQUIRE_FIXTURES=1` ⇒ 失败

- 同一环境 + 该变量 ⇒ **退出码非 0**，错误信息说明「CI 要求夹具必须存在」
- 判据：贴输出与退出码

### AC-003 · 夹具存在时行为不变

- 夹具齐全时，同一条用例的**断言内容与之前完全一致**（不是"改成只打印"）
- 判据：夹具齐全跑一遍，绿；且断言条数/内容与改动前一致（可对比 git）

### AC-004 · 只改测试基础设施

- ⛔ 产品代码零改动（`src/` 下 diff 为空）
- ⛔ 四红线 / `tools.rs` / `guard()` / `property_filter.rs` 零 diff
- ⛔ 无新依赖
- 判据：`git diff --stat develop..HEAD` 只出现 `tests/` 下的文件

### AC-005 · 跳过清单可数

- 报告列出「哪些用例会跳过」及各自缺什么夹具
- 判据：清单与 AC-001 的输出条数一致
