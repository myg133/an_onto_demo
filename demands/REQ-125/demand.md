# 需求：REQ-125 · 内部工作台前端（自包含页面）

## 基本信息

| 项 | 值 |
| --- | --- |
| 需求编号 | REQ-125 |
| 优先级 | **P1** |
| 状态 | 进行中 |
| 基线 | `develop`（REQ-124 合并后） |
| 前置 | REQ-124（控制面 API）、REQ-111（评审）、REQ-122（查询） |

## 目标

把 REQ-124 的 10 组端点变成**能点的界面**，给 FDE/实施用：

```
ontok console serve …        →  浏览器打开 http://127.0.0.1:8899/
   ├─ 项目与版本
   ├─ 评审（双轨 + AI 建议 + 批量预览）
   ├─ 导出（TTL / R2RML）
   ├─ 声明编辑（exclusions / policy / tenancy，带校验回执）
   ├─ 审计
   ├─ 查询台（含 warnings / coverage / join_states）
   └─ 目录浏览（catalog / describe）
```

## 形态：自包含页面（与既有页面一致）

| 约束 | 说明 |
| --- | --- |
| 单文件 HTML（内联 CSS/JS） | 与 `server/page.rs`、`review_ui/page.rs` 同风格 |
| **零外部依赖** | ⛔ 无 CDN、无 `script src`、无 `link href` |
| 服务端不注入数据 | 页面壳**零数据**（与 REQ-110 的 `/` 同一纪律） |

## 认证：**页面壳公开，数据靠 token**

浏览器导航无法带 `Authorization` 头，所以：

```
GET /             → 200，零数据壳（含「输入管理口令」输入框）
输入口令 → 存 sessionStorage → 所有 fetch 带 Authorization 头
```

| 规则 | 说明 |
| --- | --- |
| token 只存 `sessionStorage` | ⛔ 不落 localStorage（关浏览器即失效）、⛔ 不进 URL |
| 刷新页面 | 同一标签页仍在（sessionStorage 语义），新标签页需重输 |
| 401/403 | 清 token + 回登录态 + 显示原因 |
| 页面壳 | **零数据**：项目名、对象名、版本号一律不出现 |

> 这是**内网 + 回环 + 管理员**场景下的取舍；客户门户（REQ-126）不能用同一套。

## 范围

### 做

1. 登录态（口令输入 → sessionStorage → 带 token 请求）
2. **项目与版本**：列表、冻结状态、对象/关系计数
3. **评审**：条目列表（双轨状态、置信度、AI 建议与依据）、逐条签、批量前**显示将影响条数**
4. **导出**：TTL（客户/建模视图）、R2RML（含 `--include-inherit` 开关）→ 下载
5. **声明编辑**：三份声明的读取/编辑/保存；**保存失败保留用户输入**并显示 `code/message/hint`
6. **审计**：最近 N 条，可按动作过滤
7. **查询台**：输入 SPARQL → 结果表格 + `warnings` / `coverage` / `join_states` / `truncated` **必须显示**（不能只给表格）
8. **目录浏览**：类/属性/关系（含 `joinVerified` 等级）+ 枚举值
9. 危险操作二次确认（apply / freeze / 声明保存），确认框写明**目标与后果**

### 不做

- ⛔ 不做抽取（REQ-124 也没做）
- ⛔ 不做客户门户（REQ-126，另一套服务与凭证）
- ⛔ 不引前端框架/构建链
- ⛔ 不在页面里做租户切换（管理端才有跨租户调试，且走 API 审计）

## 关键裁定

| # | 问题 | 裁定 |
| --- | --- | --- |
| R1 | 页面是否与 API 同服务 | **是**（`console serve` 同时提供 `/` 页面与 `/api/*`），但页面壳**零数据** |
| R2 | token 存储 | `sessionStorage`；⛔ URL / localStorage / 日志 |
| R3 | 危险操作 | 二次确认 + 显示目标（项目/版本/提案）+ 后果（「将新建版本，不可撤销」） |
| R4 | 声明保存失败 | **保留编辑器内容**（不重载、不清空），显示 `hint` |
| R5 | 查询结果 | 必须显示 `warnings`（漏数据）与 `join_states` 的 `used=false`（涉及但未用） |
| R6 | 页面体积 | < 200 KB（单文件） |

## 风险

| # | 风险 | 缓解 |
| --- | --- | --- |
| 1 | XSS 偷 sessionStorage 里的 admin token | 全部输出走 `textContent`/转义；页面无 `innerHTML` 拼接用户数据；CSP 头 |
| 2 | 页面壳泄漏项目/对象名 | 与 REQ-110 同纪律：壳内 grep 项目名/对象名 = 0 |
| 3 | 误操作 apply/freeze | 二次确认 + 后果文案 |
| 4 | 大结果集卡死浏览器 | 表格分页/虚拟滚动，或限制显示行数 + 提示 |
