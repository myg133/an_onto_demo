# 验收标准：REQ-114 · 页面图交互升级

> **核心**：图要**能手动整理**（拖得动、不重叠），并且**不许为此引入外部依赖**。

## 一 · AC

### AC-001 · 节点可拖拽，且松手保持固定

- 按住节点拖动 ⇒ 节点跟随指针；松手后**位置保持**（不被下一帧力导向冲掉）
- 双击节点 ⇒ **释放固定**，回到力导向
- 判据（源码级）：存在 `pointerdown`/`mousedown` 绑定在节点上、存在 `pinned` 状态、存在双击释放逻辑

### AC-002 · 碰撞消解（防重叠）

- 每帧对距离小于「半径和 + 间隙」的节点对做**位置推离**
- 判据（源码级）：存在碰撞循环（遍历节点对、按最小间距推开）
- 判据（**行为级，必须有牙**）：**无斥力场景**（`REP=0`）下 83 节点同坐标 × 300 帧仍无重叠 ⇒
  删掉碰撞调用 / 改成注释 / 包进 `if(false)` 时**必须红**（QA 首轮实测这三种变异原先都是假绿）
- 判据（静态）：抽内核后**剥注释**再数碰撞调用点，要求**恰好 2 处**（不是 `>= 1`）
- 判据（数据级）：把 83 个节点放在同一坐标启动布局 300 帧后，**任意两节点中心距 ≥ 其半径和**（可用 Node 跑纯函数验证）

### AC-003 · 拖拽不触发点击

- 位移 > 4px 的按下-松开序列**不得**打开详情面板
- 判据（源码级）：存在位移阈值判断

### AC-004 · 视图操作完整

- 滚轮缩放（保留）、拖背景平移（保留）、**「适应窗口」**、**「重置」**
- 判据：两个按钮存在且绑定；重置后 `k=1, x=0, y=0`

### AC-005 · 标签不互相压住

- 缩放 `k < 0.6` 时隐藏节点标签（或缩短）；或按避让规则跳过重叠标签
- 判据（源码级）：存在基于 `k` 的标签显隐逻辑

### AC-006 · 搜索与定位

- 输入名称 ⇒ 高亮匹配节点；回车 ⇒ 视图平移到该节点
- 判据：输入框存在 + 匹配/平移逻辑存在

### AC-007 · 零外部依赖

- 页面内 `<script src=` / `<link href=` **0 处**（除相对路径的同源 API 调用）
- 判据：grep 页面 HTML；页面大小 < **60KB**

### AC-008 · 数据面不扩大

- `GET /` 仍返回**零数据壳**（项目名/对象名 0 命中）
- `/api/*` 无 token 仍 401（REQ-110 AC-005/006 继续成立）
- 判据：重跑 REQ-110 的那两条判据

### AC-009 · golden 重锚合规

- `tests/fixtures/req107/golden/H1_index.html` 更新；`SHA256SUMS` 同步；`PROVENANCE.txt` **写明「REQ-114 改了页面交互」**
- 判据：其余 12 份 golden 字节未动；判据仍逐字节

### AC-010 · 不退化

| 项 | 约束 |
| --- | --- |
| ⛔ 禁改 | 四红线 + `tools.rs` + `guard()` + `property_filter.rs` G1–G4 + `src/server/http.rs` |

| 基线 | REQ-112 合并后的 lib/doc/套件数字，一条不许少 |

### AC-011 · 如实登记「未做浏览器手测」

- 本机无 headless 浏览器 ⇒ 交付物必须写「未做真浏览器手测」，并列出**源码级判据**清单
- ⛔ 不许写「已验证交互流畅」这类无法证的结论
