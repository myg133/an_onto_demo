# 需求：REQ-114 · 页面图交互升级（可拖拽 / 防重叠 / 可用性）

## 基本信息

| 项 | 优先级 | 状态 | 基线 |
| --- | --- | --- | --- |
| REQ-114 | **P1** | 进行中 | `develop` `e9755e8` |

## 需求描述

### 用户实测反馈

> 「html ui 有问题，太简陋了，graph 的点也无法拖动，导致重叠遮挡。」

现状（`src/server/page.rs` 的 `INDEX_HTML`）：

| 项 | 现状 |
| --- | --- |
| 布局 | 一次性力导向，**算完就固定** |
| 拖拽 | ❌ **没有**。节点重叠时用户无法手动分开 |
| 防重叠 | 只有斥力，**没有最小间距约束** ⇒ 度高的节点会糊在一起 |
| 缩放/平移 | 有（`view.k` + `translate`） |
| 标签 | 全部常显，密集处**文字互相压住** |
| 详情 | 点击节点走 `/api/node`（已有） |
| 重置 | ❌ 没有「适应窗口 / 重置视图」 |

### 目标

一个**能手动整理**的图：拖得动、不重叠、缩得清、点得开。

## 范围

### 做（全部在 `src/server/page.rs` 的页面 JS/CSS 内，零外部依赖）

1. **节点拖拽**：按下拖动、松手后**保持固定**；双击节点释放固定并回到力导向
2. **碰撞消解**：每帧对重叠的节点对做**最小间距推离**（不是只靠斥力）
3. **拖拽与点击区分**：移动超过阈值（如 4px）不算点击，避免拖完弹出详情
4. **视图操作**：滚轮缩放（已有）、拖背景平移（已有）、**「适应窗口」+「重置」按钮**
5. **标签避让**：按缩放级别隐藏/缩短标签；或标签做简单避让（不重叠优先）
6. **搜索高亮**：输入框按名称过滤/高亮，回车定位到该节点
7. **视觉升级**：节点大小按属性数、颜色按档位（若无置信度则统一）、边箭头表示方向、图例、悬停提示

### 不做

- ⛔ 不引入任何外部 JS 库 / CDN（页面必须离线自包含）
- ⛔ 不改 `/api/graph` 的数据结构（只改渲染）
- ⛔ 不改 `serve` 的路由与门禁（REQ-110/111 的零 diff 要求继续有效）
- ⛔ 不在页面里暴露项目名/版本以外的数据（REQ-110 AC-005 的零数据壳仍必须成立）
