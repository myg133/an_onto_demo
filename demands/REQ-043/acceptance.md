## AC-001 · 【最优先】配平提取器必须跳注释

`tests/test_connect_retry.rs:253` 的 `balanced_call` 有 `in_str` 处理**字符串字面量**，
**却没有注释处理**。

QA 实测后果：

| 变异 | 现象 |
| --- | --- |
| **BA / BB** | 行尾注释里的裸 `)` 让配平**提前归零**，真正的 `migrate` 被甩出窗口 ⇒ **真的放宽了重试范围却全绿（存活）** |
| **BC** | 良性行尾注释含裸 `(` ⇒ 配平 panic ⇒ **假红** |

**讽刺点**：判据文档 `:249-252` 专门论证过「判据不能依赖『现在恰好没有』」，
并为此实现了跳字符串 —— **同一类陷阱，字符串防了、注释没防**。

- 预期结果：**BA / BB / BC 三条变异全部变红**
- 类型：测试有效性
- **注意**：修的时候别只处理 `//`，还要考虑 `/* */` 块注释、
  行注释里的 `'`（Rust 里 `'` 可能出现在生命周期 `'a` 里，别误判成字符字面量）

## AC-002 · 【次优先】`apply.rs` 判据钉次数与退避本身

`src/db/apply.rs` 的覆盖判据只 grep 字面量 `for attempt in 0..=`（`:603-605`）：

| 变异 | 现象 |
| --- | --- |
| **C3** | 次数 `3 → 1`（= 零重试）**仍绿** |
| **C3b** | 退避整段删掉**仍绿** |

- 预期结果：**C3 / C3b 两条变异全部变红**
- 类型：测试有效性
- **判据该钉什么**：钉「重试有界」这个**性质**（比如从源码推出尝试次数上界、
  确认存在退避），而不是钉 `for attempt in 0..=` 这段文本

## AC-005 · 变异自证

本需求的核心 AC 全部是「**上轮存活变异必须变红**」：

| 变异 | 上轮 | 本轮要求 |
| --- | --- | --- |
| BA / BB（注释裸 `)`） | 存活 | **杀死** |
| BC（注释裸 `(`） | 假红 | **杀死，且是真红不是 panic 逃逸** |
| C3（次数 3→1） | 存活 | **杀死** |
| C3b（删退避） | 存活 | **杀死** |
| R3b（helper 不含 connect） | 存活 | **杀死** |
| C4（`_` 前缀 helper） | 存活 | 杀死（若做 F-4）或**如实说明为何仍存活** |

每条**真的跑过**，给**二进制名 + 运行条数**，**编译失败不算变异执行**。
**存活变异必须逐条论证**是「等价变异」还是「判据有洞」。

## 环境事实

- 共享集群 DB 很慢：`SELECT 1` p50 实测 **133~161 ms**；总连接常驻 **32~38 / 100**
- **先探延迟再判断测试慢不慢**；复现率随负载浮动，**不声称稳定值**
- 报告把「代码失败」与「环境类失败」**分开写**
- ⚠️ **运行期判据与环境类失败严格二分** —— 环境失败绝不能冒充「杀死」
- ⚠️ **`.env` 里库名就是 `notol`，忘了替换成 `ontol` 会让 DB 测试秒败，
  且症状像「集群故障」** —— 本会话已有 Dev 与 QA 各踩过一次
- 本机**没有 `psql`、没有 psycopg**
- 共享本体库**禁 DELETE / TRUNCATE / 清空表**；源库只读
- 口令只走环境变量，**绝不写进报告**；⚠️ **不要 `echo` 连接串**
  （本会话已有 Dev 与 QA 各踩过一次口令回显的坑）
