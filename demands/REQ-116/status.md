## 为什么要做

用户观察「关系除了归属没有其他的」。实测坐实：

```
82 条关系：belongs_to 79 · references 3

```

**根因是 schema 的表达能力**，不是抽取质量：

| 原因 | 后果 |
| --- | --- |
| 源库 0 外键 | 没有一条关系由 DB 声明 |
| 只能按 `*_id` 命名推断 | 天然就是「归属」 |
| DDL 里没有动词 | 「下单」「扣费」「订阅」在语言里，不在表结构里 |
| 单列外键 | 基数必然 N:1 |
