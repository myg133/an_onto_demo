# 验收标准：REQ-116 · 文档摄取与断言抽取

> **一句话**：产出的每一条断言，都必须能**在原文里逐字指出来**。指不出来的，丢弃并计数。

## 一 · AC

### AC-001 · 只吃文本，其它格式显式拒绝

- `.md` / `.txt`（UTF-8）可入
- `.pdf` / `.docx` / `.doc` ⇒ **exit≠0**，报错**点名格式**并提示「先转成 .md/.txt（转换后请记下 hash）」
- 判据：三种格式各跑一次；⛔ 不许静默跳过（跳过等于装作处理过）

### AC-002 · 分块确定性

- 同一文件、同参数两次运行 ⇒ 每块的 `chunk_id` 与**块内容**逐字相同
- 判据：两次 `--chunks-only` 输出 sha256 相同

### AC-003 · 证据必须能逐字指出来（核心）

- 每条 `concept` / `relation` 的 `evidence.quote` 必须能在其 `chunk_id` 对应的**原文**中找到（CRLF/空白归一化后逐字包含）
- 找不到 ⇒ **该条丢弃**，进 `stats.rejected_no_evidence`，并在 JSONL 里**不出现**
- 判据：构造一条伪造 quote 的模型输出 ⇒ 必须被丢弃（⛔ 不许「修正 quote 让它对上」）

### AC-004 · 关系带动词（这是本需求存在的理由）

- `relation.predicate` 必须是**文档里的动词/动宾短语**（如「下单」「扣费」「订阅」），⛔ 不允许退化成 `belongs_to` 这种结构词
- 判据：真实文档跑一遍，`predicate` 分布里 `belongs_to` 占比 **< 20%**；若非（且文档本身有丰富动词）⇒ 判不达标
- ⚠️ **订正（QA 首轮 N-2）**：原判据**恒真**——`belongs_to` 在计数前就被谓词闸丢掉 ⇒ 占比结构性 0%。
  改为按**模型原始输出**算：`stats.raw_predicate_counts`（过闸前）与 `predicate_counts`（活下来）**两个都报**，
  「原始占比」才是判据；并要求构造含 `belongs_to` 的输出能把它算进去（证判据非恒真）。

### AC-005 · 模态分类，future/example 不进后续

- 每条断言带 `modality ∈ {fact, spec, future, example}`
- `future` / `example` 必须在 JSONL 里保留（供人看），但**标记为不可用于对齐**
- 判据：产出里这些标记存在；下游（REQ-117）按此过滤

### AC-006 · 确定性抽取（缓存）

- 同输入第二次运行 ⇒ **0 token**、`stats.cache_hit` 全命中、JSONL **逐字节相同**
- 判据：两次运行 sha256 + token 计数

### AC-007 · 预算闸

- `--budget-tokens N` 超限 ⇒ **停**，报告「已用 X / 上限 N / 停在第 K 块」，**不产出半份 JSONL**（或产出但明确标注 `truncated: true`——二选一，须写明）
- 判据：`--budget-tokens 1` 实测

### AC-008 · 不写库、不碰本体

- 跑前后 `concepts` / `proposals` / `ontology_versions` / `concept_groups` 行数与内容 hash 相同
- 判据：自己算

### AC-009 · 出口登记

- `doc ingest` 的产物登记进 REQ-107 的 `OUTLETS`（**内部轨**，不过客户发布闸）
- 判据：登记表里有；且**没有**把它接到客户视图

### AC-010 · 零新依赖 + 不退化

| 项 | 约束 |
| --- | --- |
| ⛔ 禁改 | 四红线 + `tools.rs` + `guard()` + `property_filter.rs` G1–G4 + `/api` 鉴权 |
| ⛔ 禁 | 删测试、`#[ignore]`、放宽断言、**新增依赖**（`Cargo.*` 零改动） |
| 基线 | REQ-115 合并后的 lib 291 / doc 4 / 75 套件 802，一条不许少 |

### AC-011 · 如实登记限制

- 中文分块按标题/段落（不是按字符数硬切）
- 多叫法不去重（对齐轮再做）
- 粒度未经真实文档调优
- 未做 PDF/Word 解析

## 二 · 纪律

- **H** 证据校验只许一处实现
- **G** 变异三元组（伪造 quote / 删证据校验 / 放宽为前缀匹配），每条必须被测试抓住
- **S** AC 也会错，发现直接说

## 三 · QA 首轮裁定（PASS 带 6 条非阻断 → 其中 2 条改判）

### A-1 · N-2 **改判阻断**：AC-004 的判据恒真

QA 实测：`belongs_to` 在计数**之前**就被谓词闸 `continue` 掉 ⇒ `predicate_counts` 里永远没有它 ⇒ 占比结构性 **0%** ⇒ 我写的「< 20%」**恒成立**。

**这是本需求的核心卖点（文档给出动词）的验证判据，它自己是空的。**

| 项 | 处置 |
| --- | --- |
| AC-004 | **已订正**：按**模型原始输出**算，同时报「原始的」与「活下来的」两个分布 |
| 判据 | 构造含 `belongs_to` 的输出 ⇒ 必须出现在 `raw_predicate_counts`，原始占比不再为 0 |

### A-2 · N-5 **改判阻断**：隐藏文件静默跳过

隐藏目录里的 `.pdf` ⇒ **exit 0 一声不吭**，而源码注释写「跳过并在 stderr 说明」。
**这正是 AC-001 禁止的 fail-open**（跳过 = 装作处理过）。要求二选一：处理并报错，或跳过但 stderr 点名 + 计数。
