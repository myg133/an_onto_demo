## 一 · 视觉语言

### 色板（`studio.css` 的 CSS 变量）

| 用途 | 值 |
| --- | --- |
| 背景 | `#070a10` |
| 面板 | `rgba(255,255,255,.028)` ／ 悬停 `.05` |
| 描边 | `rgba(255,255,255,.085)` ／ 极淡 `.045` |
| 正文 / 次级 / 三级 | `#e8edf6` / `#9aa7bd` / `#64708a` |
| **强调（可查询）** | `#6ec8ff` |
| **警示（API 源）** | `#e6b455` |
| 成功（实测证据） | `#5fd3a3` |
| 危险 | `#ef7a8a` |
| 圆角 | 12 / 8 |
| 缓动 | `cubic-bezier(.22,.61,.36,1)` |

背景用**两层径向渐变**做顶部辉光（蓝 + 紫），不用图片、不用滤镜。

### 节点（6 层结构）

```
① 辉光      radialGradient，r≈42+deg×2.6，opacity .72
② 轨道      虚线 stroke-dasharray "2 7"，r=28.5 —— 科技感的主要来源
③ 球体      radialGradient（亮斑→本体色→暗边），r=21.5，低对比
④ 边缘光    stroke 同色，stroke-width 1.25，opacity .66
⑤ 高光      左上小椭圆，白 18%（只提体积，不做"塑料反光"）
⑥ 细环      r=25.6，仅描边
```

**球面渐变要"低对比高衰减"**——高对比会变成塑料球，不是能量球。

### 三态着色（**这是语义，不是装饰**）

| 状态 | 颜色 | 含义 |
| --- | --- | --- |
| **API 源** | 琥珀 `#e6b455` | 平台不执行，查询给 `@pending` 取数指引 |
| **库源（本部署无库）** | 灰 `#5d6a80` | 查了会 503 |
| 可查询 | 青 `#6ec8ff` | 有源库、能走 SPARQL |

由 `catalog` 的 `access.kind` + `health.mode` **推导**，不新增后端字段。

## 二 · 交互契约

| 操作 | 行为 |
| --- | --- |
| **按在节点上拖动** | 拖这个节点（Pointer Events + `setPointerCapture`）；邻居被弹簧**轻微**带动 |
| **按在空白处拖动** | 平移画布 |
| 滚轮 | 以光标为中心缩放（0.25×–2.6×） |
| 单击节点 | 聚焦：高亮自己+邻居、其余淡化、**显示它的关系名**、右侧开详情抽屉 |
| 单击空白 | 取消聚焦 |
| **Esc** | **强制结束拖拽**（兜底） |
| 「适应」按钮 | 缩放到全屏（初始视图是 **1:1 居中**，不是 fit） |
| 「动效」按钮 | 呼吸/自转开关，**默认关** |

**初始视图必须是 1:1 居中**——用 fitView 会把布局尺度放大这件事直接抵消，屏幕上永远一样挤。

### 物理参数（改之前先读）

| 参数 | 值 | 作用 |
| --- | --- | --- |
| `K`（斥力） | 8000 | 越大越散 |
| `REST`（弹簧自然长度） | 280 | 决定边均长与画布大小 |
| `GRAV` | 0.0008 | 向心，防整体飘走 |
| `DAMP` | 0.86 | 黏滞，重量感 |
| `MIN_GAP`（碰撞下限） | 88 | **球体不得重叠** |
| `alpha` 退火 | ×0.94/帧，<0.03 停 | **保证会停** |

实测：静置/拖后都在 **56 帧（≈0.9s）** 内收敛，最近节点 105px。

## 三 · ⛔ 性能红线（**闪了三次，全是这三条**）

| # | 禁止 | 为什么 |
| --- | --- | --- |
| **①** | ⛔ **SVG 滤镜**（`feGaussianBlur` / `filter: url(#…)` / 逐元素 `drop-shadow`） | 30+ 元素的滤镜区域**每帧重算**。曾用 `bloom` 做泛光，结果整页闪。泛光改用**径向渐变**实现 |
| **②** | ⛔ **每帧 `appendChild` 重排 DOM** | 按 y 排序做"层次感"会整组重绘 → 观感就是"松手后闪一下"。已删：**用确定性换稳定** |
| **③** | ⛔ **无限动画默认开** | 2 个无限动画 × 30 节点 = 持续重绘。已改为「动效」开关，**默认关** |
| ④ | ⛔ 压在动画内容上的 `backdrop-filter` | 背后一变就要重新模糊。浮动工具条 / 底部导航已改不透明底 |

**还要记住两条实现规则**：

- **`alpha` 不许重置成 1**：那会让松手后整张图重新收敛（实测最大位移 179px）
- **DOM 只增不重排**：节点创建后位置靠 `setAttribute` 更新，**永不移动元素**

## 四 · 数据映射（只用现有 API）

| UI 元素 | 来源 |
| --- | --- |
| 类节点 | `GET /api/catalog` 的 `kind=class` |
| 属性小点（聚焦时） | `catalog` 的 `kind=property` |
| 关系边 + **证据等级** | `catalog` 的 `kind=relation`（`from`/`to`/`evidence_level`） |
| 可查性三态 | `class.access.kind` + `health.mode` |
| 查询台响应 | `POST /api/sparql`（默认 JSON-LD） |
| 详情抽屉 | `GET /api/describe?name=` |

**⛔ 不为 UI 新增后端字段**。UI 适配产品，不是反过来。

---

## 五 · 文案规则

- **`@pending` 必须解释**：不是"没数据"，是"**平台不执行，按 get 自取**"
- **`meta.complete: false` 必须标注**：这份结果**不完整**
- **`filter: {}` 必须警示**：⛔ 不要全量拉（账单类会烧钱）
- **关系证据等级必须显示**：本套 34 条关系**全部 `unverified`** ⇒ UI 里如实写"文档推断、无实测证据"
