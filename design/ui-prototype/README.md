# 元方本体平台 · 本体图样机

> **状态：视觉已确认（2026-10-26）· 未接产品代码**
> 这是**设计样机**，不是产品功能。点开 `index.html` 就能看，不依赖构建、不依赖服务。

---

## 一 · 这是什么

用**我们真实的 API 返回形状**渲染的三屏 UI 原型：

| 视图 | 内容 |
| --- | --- |
| **本体图** | SVG 力导向（30 类 / 34 关系）· 拖拽/缩放/聚焦 · 三态着色 · 证据等级 |
| **目录** | 30 张类卡片（名称 / key / 属性数 / 关系数 / 可查性） |
| **查询台** | SPARQL 编辑 + **真实 JSON-LD 响应渲染**（含 `@pending` 醒目标注） |

**数据全部来自现有接口**（`/api/health`、`/api/catalog`、`/api/describe`、`/api/sparql`），
**没有为它改过一行 Rust**。

---

## 二 · 怎么打开

```
直接双击 index.html          # 读 snapshot.js 的离线快照
```

⚠️ 若浏览器缓存了旧版本，**Ctrl+F5** 强刷。

### 换成实时数据

1. `index.html` 同目录起一个静态服务（同域，避免 CORS）
2. `studio.js` 顶部把 `USE_LIVE` 改成 `true`，并注入 `ONTOK_TOKEN`

### 重新抓快照

```bash
# 需要能访问目标部署（建议用 kubectl port-forward 到 127.0.0.1:18800）
python tools/capture-snapshot.py     # 产出 snapshot.js
```

## 三 · 文件

| 文件 | 大小 | 说明 |
| --- | --- | --- |
| `index.html` | 7 KB | 壳（三视图 + 抽屉） |

| `snapshot.js` | 460 KB | **2026-10-26 抓的本体快照**（含类/属性/关系元数据 + 3 个真响应；**无业务数据、无凭据**） |
| `preview.png` | 439 KB | 静态预览（就是本体图那一屏） |
| `tools/capture-snapshot.py` | 2 KB | 快照生成脚本 |

**为什么把 `snapshot.js` 也入库**：样机要能**脱离环境直接看**。它只有本体元数据，可以随时重生成。

## 四 · 已知缺口（都不属于"UI 没做好"）

| 缺口 | 影响 | 归属 |
| --- | --- | --- |
| `@pending.get` 只有 4 个键 | 客户端得自己拼请求 | **REQ-152 阶段 2**（`get` 给完整配方） |
| 34 条关系全部 `unverified`、`evidence` 为空 | 图上的关系全是**文档推断** | 数据现状 → UI 已如实标注 |
| 16 个类没有取数契约 | 查了 503 | REQ-153（覆盖盘点）补类 |
