# 流程图 · 从构建到消费

| 文件 | 内容 |
| --- | --- |
| [`build-to-consume.svg`](build-to-consume.svg) | **v0.3.0 全链路**：构建端（ontok-builder）→ 服务端（ontok）→ 消费端（数字员工），含每步命令与参数、四道发版闸、9+1 个退出码 |

## 怎么读
- 三条竖列 = 三个部署单元（**只部署中间那一列**）
- 实线箭头 = 主路径；跨阶段两条：**人工上传构建包**（构建端→服务端）、**HTTPS + query key**（服务端→消费端）
- `$` 开头 = 可复制命令；`#` 开头 = 判据 / 注意；`<…>` = 占位符
- 底部黄框 = **四道闸**：任何一道缺了，都会出现"看起来成功、实际不可用"
