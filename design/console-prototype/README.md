# Console 工作台 · 设计样机

> **这是设计稿，不是产品代码。** 双击 `index.html` 就能看，不依赖构建、不依赖服务。

---

## 一 · 定位（和 Studio 的分工）

| | **Console**（本样机） | **Studio**（`BA/design/ui-prototype`） |
| --- | --- | --- |
| 给谁 | **FDE / 实施** | **客户 / 业务方** |
| 干什么 | 建库、审核、导出、改声明、看审计 | 看本体图、查数据、读懂口径 |
| 视觉 | **高密度、表格优先、装饰少** | 能量球、轨道、辉光（展示性） |
| 状态 | 7 个视图 | 3 屏 |

**共用同一套 design token**（同一份色板与缓动），但**密度不同**——工具不该长得像宣传页。

---

## 二 · 7 个视图

| # | 视图 | 主要交互 |
| --- | --- | --- |
| 01 | **项目与版本** | 版本表（冻结状态/类/关系/抽取来源）+ 导出入口 |
| 02 | **评审** | 64 条（30 类 + 34 关系）逐条 ✓/✕ · 批量接受 · AI 建议列 |
| 03 | **导出** | 参数表单 + TTL 预览（等宽，可滚动） |
| 04 | **声明编辑** | 三个 tab（exclusions / policy / tenancy）+ **保存前校验清单** |
| 05 | **审计** | 时序表（时间/动作/令牌 sha 前 12/结果） |
| 06 | **查询台** | SPARQL 编辑 + 三个样本（api 类 / 库源类 / 计数）+ 响应原文 |
| 07 | **目录浏览** | 30 类表（属性数/关系数/取数/证据）+ 搜索 + **右侧抽屉看详情** |

## 三 · 设计决定（几条有意为之）

| # | 决定 | 为什么 |
| --- | --- | --- |
| 1 | **左侧窄导航 + 单一主区**，不用顶栏 tab | 7 个视图是并列的，顶栏放不下；左栏能常驻显示连接状态 |
| 2 | **表格行高 32px、表头 sticky** | 内部工具要一屏看 20+ 行；滚动时不丢表头 |
| 3 | **key / IRI 一律等宽**（`.key` 类） | `cvm_instance`、`ins-70n4ge4i` 这类字符串**靠视觉模式识别**，比例字体读起来慢 |
| 4 | **状态只用一个小圆点 + 文字**（`.pill`） | 颜色不是唯一信息通道（色盲友好），且不喧宾夺主 |
| 5 | **抽屉而不是弹窗**（类详情） | 看目录时要**对照**着读，弹窗会遮住表格 |
| 6 | **声明编辑带"校验清单"** | 后端是"保存前校验、失败一个字节都不改"——界面必须先把这件事说清 |
| 7 | **查询台给三个样本而不是空白框** | 空白框没人知道能查什么；三个样本覆盖三种回执形态 |
| 8 | ⛔ **不用 `innerHTML`** | 与 Studio 同一纪律；全部 `createElement` |

## 四 · 哪些是真实数据

**全部来自 `cloud-resource` v3 的真实接口响应**（2026-10-26 抓取）：

| 数据 | 来源 | 真实？ |
| --- | --- | --- |
| 项目 / 版本 / 冻结时间 / 抽取来源 | `GET /api/projects` | ✅ 原样 |
| 30 类 / 752 属性 / 34 关系 | `GET /api/catalog`（5 页合并） | ✅ 原样 |
| 类详情（抽屉） | 同上 + `GET /api/describe` | ✅ 原样 |
| TTL 预览 | `GET /api/export/ttl` | ✅ 前 4000 字符 |
| 查询台响应 | `POST /api/sparql`（api 类 / 库源类） | ✅ 原样（含 `@pending` 与 `meta.contract_version`） |
| 审计 | `GET /api/audit` | ⚠️ 真实响应就是**空**（快照是只读抓的） |
| 评审条目 | **按真实类/关系生成** | ⚠️ 决策状态是交互态，没有真提案 |

## 五 · 已知缺口

| # | 项 | 说明 |
| --- | --- | --- |
| 1 | 不接后端 | 点按钮不会真发请求（样机） |
| 2 | 声明编辑不落盘 | 只有前端校验，真校验在后端 |
| 3 | 评审没有真提案 | 决策不落审计 |
| 4 | 移动端 | 只做了一档窄屏折叠，没细调 |
