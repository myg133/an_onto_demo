# 需求与设计管理（demand 分支）

| `demands/` | 需求文档（REQ-xxx） |

| `sprint/` | 迭代计划 / 回顾 |
| `decisions/` | 架构决策记录（ADR） |
| `dispatch/` | 调度与 Agent 注册表 |
